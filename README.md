# Vicare Video Publish — public information

Static application introduction and privacy notice for a personal, local video publishing tool.

This repository contains only public documentation pages. It does not contain the uploader implementation, credentials, media, or private workspace data.

- `index.html`: application introduction
- `privacy.html`: data handling notice
- `style.css`: shared local styles

Hosted on GitHub Pages. No client-side JavaScript, login form, upload form, or analytics scripts.
